# Team portraits — generation briefs

The Team page renders one card per person below. Generate a portrait for each, save it with the
**exact filename** shown (JPG or PNG both work — the page tries `.jpg` then `.png`), and drop it in
this folder (`assets/team/`). Cards show a neutral placeholder until the file exists, so the page works
before every portrait is in.

**Global style — keep all portraits consistent so they read as one team:**
> Editorial headshot, shoulders-up, facing camera, friendly-professional expression, soft natural light,
> plain warm off-white background (#fbf7f0), subtle depth of field, photorealistic. Square (1:1) crop.

Then append each person's one-line brief below to that global style.

> Note: these are the **AI specialists** ("agents") that write, translate, and build Logia's books — the
> Team page presents them as a studio crew (an AI-native company). Names are ours to choose; rename any
> you like and update `team.html` + the filename to match.
